## 2. 🔴 자기잠식 경고 - 홈피 글 설계가 여기서 갈린다

홈피 `/content`에 이미 **AI 영상·이미지 글이 19편** 있다.

```
무료-ai-영상-사이트-3가지 / 구글-플로우-ai-영상-만들기 / 클링-ai-사진으로-영상-제작
클로드코드-리모션-ai-영상-만들기 / comfyui-클로드코드-ai-이미지-영상-무료-생성
구글-veo2-감성-홍보-영상 / 캔바-영상만들기 / 무료-ai-이미지-사이트-3가지 …
```

여기에 "AI 영상 만드는 법" 글을 하나 더 쓰면 **서로 검색을 잡아먹는다**(메모 `lecture-post-seo-rules` §4).

→ **책 소개글은 개별 툴 사용법이 아니라 허브(pillar)로 만든다.**

```
        [홈피 책 소개 허브글]  ← AI 영상 제작 전체 프로세스 · 툴 선택 기준 · 20개 프로젝트
         ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
    기존 19편(스포크, 개별 툴 실전)  ← 각 글 하단에 허브 링크 삽입
```

- 허브는 **"무엇부터, 어떤 순서로, 어떤 툴로"**를 답한다. 개별 툴 실습은 스포크에 넘기고 링크만.
- 기존 19편은 이미 색인된 자산이다. **하단에 허브 링크 한 줄 + 책 링크를 소급 삽입(retrofit)하는 게 신규 글보다 즉시 효과가 크다.**
- AEO에서도 허브 구조가 유리하다. AI는 "전체를 조망하고 출처가 명확한 페이지"를 인용한다.

```
1. 첫 문단 = 무슨 책인지 1~2문장 + 모집 사실 (빌드업 금지)
2. 책 실물 - 표지·본문 미리보기 3~4장 (『최종 보도자료 표지 미리보기』 폴더)
3. 이 책이 뭘 하는 책인가
   - 20개 프로젝트 리스트 (실제 결과물 유튜브 링크 3~4개 심기)
   - 다루는 툴 12종 (캡컷·브루·수노·일레븐랩스·클링·미드저니·헤이젠·플로우·나노바나나 …)
4. 서평단 모집 요강 (표)
5. 신청 방법 - 구글폼 링크 (댓글 금지: 개인정보 노출)
6. 서평단 특전
7. 서점 링크 3사 + 프롬프트 사이트
```

**본문에 반드시 넣을 것**: 완성 영상 링크. "책에 나온 예제 결과물을 지금 볼 수 있다"가 이 책의 최대 무기고, 자산목록 `QR_완성영상_36개.md`에 URL이 다 있다.

### 4-2. 브런치

브런치에서 「서평단 모집」 검색 유입은 없다. **구독자에게 읽히는 글**이므로 이벤트 공고를 그대로 옮기면 안 된다.

**구조 = 에세이 8:2**

```
제목안: "AI가 영상을 만드는 시대에, 왜 296쪽짜리 책을 썼나"
        "영상 한 편에 3일 걸리던 사람이 10분으로 줄이기까지"

1. 왜 이 책을 썼나 (기자 → 콘텐츠 크리에이터 → AI, 개인 서사)
2. 쓰면서 알게 된 것 - 툴은 바뀌지만 프로세스는 안 바뀐다
   (실제로 집필 중 이미지FX·위스크·소라가 종료돼 원고를 갈아엎은 경험 = 이 책의 핵심 논지 그 자체)
3. 그래서 책은 툴 설명서가 아니라 프로세스 책이 됐다
4. 마지막 단락에서만 서평단 안내 + 홈피 링크
```

에세이 톤 규칙은 `content-republish` 스킬 §브런치(팁·실습 제외, 서사 유지)를 따른다.

| meta desc | AI 영상 제작을 처음 시작할 때 필요한 순서를 정리했습니다. 캡컷·브루·수노·일레븐랩스·클링·미드저니 등 툴 12종의 용도와 무료 범위, 20개 실전 프로젝트의 제작 흐름을 담았습니다. |

기존 19편과 겹치지 않게 **"순서 · 비교 · 전체 프로세스"**를 축으로 잡는다. 개별 툴 이름은 본문 표에만 두고 제목에서 뺀다(스포크와 충돌 방지).

### 5-2. AEO 설계 (AI 검색 인용용)

AI가 인용하는 페이지는 **질문에 즉답하고, 표로 정리되고, 출처·저자가 명확한** 글이다.

**질문형 H2 + 첫 2~3문장 즉답** 구조:

```
H2  AI 영상 제작, 어떤 순서로 배우는 게 빠를까요?
    → 즉답 2문장 (프롬프트 7요소 → 이미지 → 영상 → 소리 → 편집)
H2  툴은 몇 개나 알아야 하나요?
    → 즉답 + 툴 12종 비교표
H2  무료로 AI 영상을 만들 수 있나요?
    → 즉답 + 무료 범위 표 (⚠️ 가격 수치는 변동 잦으니 "무료 할당량" 표현, 책 편집 원칙과 동일)
H2  AI로 만든 영상을 상업적으로 사용해도 되나요?
    → 즉답 + 툴별 약관 확인 포인트 (책 ch1-14~16, 검수 때 약관 원문 전수 검증한 자산)
H2  AI 영상 제작, 얼마나 걸리나요?
    → 즉답 (프로젝트별 단계 수: 키보드ASMR 19단계, 공룡 17단계 …)
H2  이 책은 무엇을 담고 있나요?
    → 목차 전문 + 20개 프로젝트 표 + 완성 영상 링크
```

**구조화 데이터 2종**
- `Book` schema: name, author, publisher, isbn(9791194116240), numberOfPages(296), datePublished(2026-08-01), offers, workExample
- `FAQPage` schema: 위 질문형 H2를 그대로 매핑

**AI가 물어갈 재료 = 표 3개**
1. 툴 12종 × (용도 / 무료 범위 / 난이도)
2. 20개 프로젝트 × (챕터·쪽 / 쓰는 툴 / **완성 영상 링크**)
3. 학습 순서 5단계

3번 표의 완성 영상 링크가 결정적이다. **"결과물을 실제로 확인할 수 있는 책"**은 검색 결과에서 우리만 갖고 있다.

### 5-3. 내부링크 (허브 & 스포크)

- 허브 → 스포크: 툴 표의 각 행에서 기존 글로 (구글 플로우 / 클링 / ComfyUI / 캔바 / 무료 AI 영상 사이트 …)
- 스포크 → 허브: **기존 19편 하단에 "전체 순서가 궁금하면" 한 줄 + 책 링크 소급 삽입** ← 1차 발행과 같은 커밋에 처리
- 허브 → 프롬프트 사이트(`book.storywinner.co.kr/ai-video/`) → 서점

| **수노** | **34,700** + Suno AI 16,900 | ch2-03 AI 작곡 | "내 영상 BGM을 직접 만든다"가 선명. 결과물 공유성 높음 | 경쟁 높음 |
| 나노바나나 | 30,500 | ch1-10 · ch3 | 트렌드 최상위 | 유행성, 수명 짧음 |
| 일레븐랩스 | 16,440 (중간) | ch2-04 보이스 | 경쟁 중간, 실무 수요 확실 | 유입 규모 중간 |
| AI 저작권 | 630 | ch1-14~16 | **AEO 최강 소재.** 약관 원문 전수 검증본 보유 = 아무도 못 쓰는 글 | 검색량 작음 |

**추천 편성**
- **2차 = 수노** (AI 음악). 단독 주제로 선명하고, 책 ch4-07 Kpop 챌린지 결과물이 증거로 붙는다. 제목에 "수노 사용법 1,020(중간)" 롱테일 병기.
- **3차 = 캡컷** (무료 편집). 최대 유입 소재를 리뷰가 쌓인 시점에 던진다. + 서평 모음 코너 병행.
- **저작권 글**은 검색량이 아니라 **AEO·신뢰 자산**으로 별도 취급. "AI 영상 상업적 이용" 질문에 우리가 답하는 페이지가 되면 강의·기업교육 문의로 이어진다. 여력 되면 3차에 붙인다.

**각 글의 공통 구조 (구매 유도 설계)**
```
1. 이 툴로 뭘 만들 수 있나 - 완성 결과물 먼저 (책 예제 영상)
2. 실전 순서 (책에서 한 프로젝트를 통째로 공개. 아끼지 않는다)
3. 막히는 지점 2~3개와 해결
4. "나머지 19개 프로젝트는 책에" + 프롬프트 사이트 → 서점
```

⚠️ **하나는 완결되게 준다.** "자세한 건 책에"로 끊으면 배신감이 남는다(쇼츠 안티패턴과 동일 원칙). 한 프로젝트를 끝까지 주고, 확장을 책이 담당한다.
