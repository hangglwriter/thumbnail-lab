**승리 요인 6가지**:
1. **준비가 본편** - 12분 중 4분 20초가 에이전트 실행 "전". 메시지 = "에이전트는 준비를 잘 준 만큼 잘한다" (툴 시연이 아니라 방법론 전수)
2. 결과물 선공개로 시청 동기 선지급
3. 저장 유도 실무 팁 3개 이상 심기 (@태깅, reuse prompt vs edit, 음악 컷 타이밍)
4. 실패 컷도 보여주고 대응법 제시 (정직 → 신뢰)
5. 에이전트 한계 인정 (편집·음악·마지막 감각은 사람) - 과장 없음
6. 무료 리소스 목록 제공 (설명란 링크 = 받아가라 CTA)

### G5 키워드 전략 (8/3 확정, 실측 근거)

- **"구글 에이전트" 단독 메인 = 함정**: 검색 결과 25건 전부 업무 자동화·비서·시사 문맥(GEM 야근탈출 29.5만, KBS 다큐 27.7만, 스브스뉴스 7/30). 영상 제작 문맥 0건 → 검색 의도 미스매치 (검색량은 있는데 의도가 다른, "구글 옴니 440"과 반대 유형의 함정)
- **"플로우 에이전트" = 성장 선점 키워드**: 검색 의도 정확(25건 전부 영상 제작), 에이전트 전용 영상은 소형 3~4개뿐(노모어매뉴얼 2.4만이 최대). 모수는 아직 작지만 "구글 플로우"(현 22,840)의 초기와 같은 궤적 기대
- **해외 실측**: Flow Agent 전용 콘텐츠 17~18건 형성 중 (구글 공식 7.4만·4.2만, Keera 제작기 5.9만이 크리에이터 1위, 8/2에도 신규 업로드 = 진행형). 해외도 초기, 대박 없음 → 한국 선점 여유 있음
- **제목 공식**: "구글 플로우 에이전트"를 이어 쓰면 한 구절에 "구글 플로우"(현재 모수)+"플로우 에이전트"(성장 선점)+"에이전트"(시대 훅) 3패턴 포함
  - 가안: **"요즘 난리라는 AI 에이전트, 영상도 만듭니다 - 구글 플로우 에이전트에게 한 편을 통째로 맡겨봤습니다"**
